# Hiba Faraz Portfolio

React + Vite + Tailwind CSS + Framer Motion + React Router.

Pages: Home, Work, Promotions, About, Services, Contact.

## Run
    npm install
    npm run dev        # local preview
    npm run build      # production files in /dist

## Edit content
All text, links, email, WhatsApp, photos, work tiles and promotion brands are in
`src/data.js`. Put photos in `/public` and use paths like "/hiba.jpg".

## Deploy
Upload the `dist` folder to Netlify (the `_redirects` file is already included),
or use Vercel / Cloudflare Pages.
